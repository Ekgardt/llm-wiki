# `tests/test_workspace_revision_private_index_semantics.py`

The private-index fast path of a revision check is taken only when git's configuration, attributes and index cannot change what it reads.

Providers outside the module appear in the packet either whole or as their exact
derived description; the `-context.json` manifest next to this guide lists the
complete maintenance context and the tests that qualify each description.

Run `uv run pytest tests/test_workspace_revision_private_index_semantics.py -q`.
