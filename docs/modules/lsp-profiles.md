# Managed language registry

`scripts/lsp_profiles.py` owns the complete existing Pyright, TypeScript, Go and
Rust server declarations, suffix routing, configuration names and notification
union. Source bytes are unchanged in this qualification. Existing platform
artifacts, package pins, readiness/identity policies and launch declarations
remain exact. Reading declarations neither installs nor launches a server.

Dependencies are lsp_paths, lsp_server_profile and immutable Pyright configuration;
the complete sources and guides are included. The registry must not import
pyright_profile, runtime coordination or process owners. The existing isolated
import regression verifies that boundary in a fresh subprocess.

Twenty-one original registry test functions moved with unchanged bodies and
parameters. Six cross-owner equivalence tests remain integrated with the session,
protocol and discovery owners. The shared absolute-path fixture remains in the
generic profile test packet and is included here without copying it. Source and
test evidence, instruction/bootstrap and measurement code are counted in the
complete <=100000-token packet. Run `pytest tests/modules/lsp_profiles
 tests/test_language_registry_has_no_discovery_dependency.py
 tests/test_lsp_server_profile.py -q`.

Declarations and pure platform-path cases are not proof of installed artifact
identity, native startup or semantic answer quality; those consumers retain their
existing checks. This qualification changes no supported server or version.
