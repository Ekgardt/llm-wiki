# Project history: memory compilation, part 1 of 2

This packet owns 26 dated research, plan, audit or report records about memory compilation from 2026-08-21 to 2026-10-04.
Each record states what was measured or decided when it was written. It is evidence, so it
is not rewritten to follow the code; a later decision supersedes it with a new dated record.

The packet holds no executable source and no runtime state. Records were grouped by a keyword
in their file name, then by date, to give a reader one bounded place to look; the grouping is
navigation and makes no claim about a record's content.

The owned files and the complete maintenance context are listed in the `-context.json`
manifest next to this guide.
