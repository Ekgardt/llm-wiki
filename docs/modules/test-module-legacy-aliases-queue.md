# `tests/test_module_legacy_aliases_queue.py`

The queue facade's legacy names are the artifact, task-record and evidence-record owners' objects, with no second implementation, and their rows and evidence keep their pickle identity.

Providers outside the module appear in the packet either whole or as their exact
derived description; the `-context.json` manifest next to this guide lists the
complete maintenance context and the tests that qualify each description.

Run `uv run pytest tests/test_module_legacy_aliases_queue.py -q`.
