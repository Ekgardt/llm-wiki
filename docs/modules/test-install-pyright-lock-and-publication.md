# `tests/test_install_pyright_lock_and_publication.py`

Its tests hold the managed Pyright installer to one owned lock, cleanup of only its own scratch, and publication of a complete tree or none.

Providers outside the module appear in the packet either whole or as their exact
derived description; the `-context.json` manifest next to this guide lists the
complete maintenance context and the tests that qualify each description.

Run `uv run pytest tests/test_install_pyright_lock_and_publication.py -q`.
