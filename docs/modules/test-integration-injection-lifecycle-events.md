# `tests/test_integration_injection_lifecycle_events.py`

The OpenCode plugin forwards lifecycle events once, normalization keeps only available signals, and checkpoint observation never blocks durable capture.

Providers outside the module appear in the packet either whole or as their exact
derived description; the `-context.json` manifest next to this guide lists the
complete maintenance context and the tests that qualify each description.

Run `uv run pytest tests/test_integration_injection_lifecycle_events.py -q`.
