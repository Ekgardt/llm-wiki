# Project governance

The rules every contributor and agent works under, and the repository settings that enforce them: the operating contract, the development laws, the contribution guide and the ignore, secret-scan and hook configuration. `AGENTS.md` and `CLAUDE.md` stay byte-identical; `.gitignore` is what keeps private knowledge out of the public repository.

The owned files and the complete maintenance context are listed in the `-context.json`
manifest next to this guide.
