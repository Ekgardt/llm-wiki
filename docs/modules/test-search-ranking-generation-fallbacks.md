# `tests/test_search_ranking_generation_fallbacks.py`

A generation that is missing, mismatched, malformed or changes under a query falls back to Markdown or the base ranking and never mixes legacy evidence.

Providers outside the module appear in the packet either whole or as their exact
derived description; the `-context.json` manifest next to this guide lists the
complete maintenance context and the tests that qualify each description.

Run `uv run pytest tests/test_search_ranking_generation_fallbacks.py -q`.
