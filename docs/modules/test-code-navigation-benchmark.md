# `tests/test_code_navigation_benchmark.py`

Behavioral tests for the deterministic Python navigation qualification fixture, its pinned identity and its arithmetic.

It also owns `tests/code_navigation_benchmark_runtime_helpers.py`, the helpers other test files import from it.

Providers outside the module appear in the packet either whole or as their exact
derived description; the `-context.json` manifest next to this guide lists the
complete maintenance context and the tests that qualify each description.

Run `uv run pytest tests/test_code_navigation_benchmark.py -q`.
