# `tests/test_lifecycle_delegate_receives_redacted_payload.py`

A lifecycle delegate receives only the normalized, redacted payload, and the host sees nothing on stdout.

Providers outside the module appear in the packet either whole or as their exact
derived description; the `-context.json` manifest next to this guide lists the
complete maintenance context and the tests that qualify each description.

Run `uv run pytest tests/test_lifecycle_delegate_receives_redacted_payload.py -q`.
