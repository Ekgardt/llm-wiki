# An unchanged ambiguous row cannot gain a protected alias

On 2026-10-07, source-choice preparation repeatedly protected the complete input packet after an unchanged row failed original evidence binding. Thirty numeric lines reproduced twelve unnecessary fallback calls. A dense 3,000-line fixture spent about 140 CPU seconds planning one batch and preparing its final prompt.

A protected binding must resolve an altered original row at one of that choice's physical positions. If every offered position still contains the exact original quote, protection cannot repair an ambiguous or missing original binding at those positions. The source-choice boundary now records that narrow fact for the current immutable inputs and exact date, timestamp, and quote. Original evidence validation still runs through the shared boundary, including physical-line, selected-part, digest, span, and resolver checks. Its original error is preserved when no protected alias is physically possible. Changed rows and other quotes retain the existing protected binding path. The request-local fact is reset even when binding raises.

Alternatives were exercised rather than assumed. Reusing pure parsing did not improve complete planning and was removed. Bypassing the shared binding seam failed an existing test; a subsequent original precheck resolved valid evidence twice and failed another. Those variants remain qualification evidence, not installed code. The final scope preserves both protections without duplicating resolution or caching accepted authority.

The combined capacity-grouping candidate passed 356 related Python 3.10 tests. A paired local measurement preserved the complete original source, batch count, and exact 22,204-byte final prompt: about 140 CPU seconds before and 1.81 seconds after. These figures concern local preparation on this fixture, not model latency or full-cycle token efficiency. This standalone change does not install the separate capacity-grouping candidate; its own related checks and installed-byte verification are required.
