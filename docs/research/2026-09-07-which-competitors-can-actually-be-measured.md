# Кого из конкурентов можно измерить, а кого нет — 2026-09-07

Владелец попросил стенд с конкурентами по навигации по коду. Прежде чем что-то
ставить — кто вообще годится.

## Годятся

| инструмент | лицензия | как запускается | где живёт |
|---|---|---|---|
| codebase-memory-mcp | MIT | уже стоит, `cbm cli --json` | локально |
| trace-mcp 3.22.0 | MIT | `npx -y trace-mcp@3.22.0` | локально, SQLite в `~/.trace-mcp` |
| Serena | MIT, 28 948 звёзд | `uvx --from git+…/serena` | локально, прокси к языковому серверу |

## Не годятся, и почему

**Graphify.** Пакета в npm под этим именем нет: `npm view graphify` отдаёт
«RGG (Random Graph Generator)» — генератор случайных графов, к коду отношения
не имеющий. Поставить его вместо Graphify было бы ошибкой, и это ровно та
ошибка, которую правило про зависимости и должно предотвращать. `graphify.net`
отвечает 403, самостоятельно разворачиваемого исходника не нашлось. Похоже на
размещённый сервис: измерить его можно, только отправив туда код, а этого
делать нельзя. **Исключён.**

**codegraph (npm).** Версия 1.0.0, описания нет, репозиторий не указан.
Незнакомый пакет без происхождения не ставится. **Исключён.**

**code-review-graph.** Python, MIT по обзорам, но собственного источника
установки не подтвердил. Отложен до проверки, не исключён.

## Что нужно знать перед установкой

**trace-mcp** несёт команды, которые трогают чужое: `init` и `setup-hooks`
прописывают хуки в Claude Code и правят `CLAUDE.md`. В стенде запускается
только `add`, `index` и `serve`; `init` и `setup-hooks` не запускаются никогда.
Отдельно: у него есть `consent` для исходящего трафика к провайдерам моделей —
согласие не даётся, замер должен быть локальным с обеих сторон.

**Serena** пишет каталог `.serena/` в проект. Он не должен попасть ни в git,
ни в `knowledge/`.

## Чем звать

`cbm` умеет `cli --json <tool> <args>` — поэтому существующий стенд зовёт его
подпроцессом. Ни trace-mcp, ни Serena такого режима не имеют: они говорят по
MCP через стандартный ввод-вывод. Значит стенду нужен маленький клиент MCP:
поднять сервер, `initialize`, `tools/call`, прочитать ответ, погасить. Он же
потом годится для любого следующего конкурента.

## Что честно сравнивать

Расход токенов у сторон меряется одинаково: длина текста, который инструмент
вернул агенту. Индексация в стоимость вопроса не входит ни у кого — она разовая
и у cbm тоже не входит.

Оговорка, которую надо будет повторить в отчёте: у trace-mcp и Serena набор
инструментов другой, и подобрать для каждой из 13 задач «тот самый» вызов —
работа руками. Плохо подобранный вызов занижает чужой результат, и это будет
не их слабость, а наша небрежность. Поэтому у каждой стороны, как уже сделано
для нас самих, будет два набора: как настроено и «лучшая поверхность».
