Date: 2026-11-17. Scope: pull request #57 (module decomposition, Python 3.14, branch audit).

Main had tests that this branch no longer has under the same name. Four came back under
their original names, and the five split MCP test files kept the class names their tests had
before the split. The tests listed here were not restored, because the behaviour
they asserted was deliberately changed, removed as an unjustified limit (law 9) or made
obsolete by the move to Python 3.14. Each row names the change and the tests that now
guard the behaviour. Every guard named here exists on this branch;
`tests/test_removed_tests_have_guards.py` checks that against this file.
