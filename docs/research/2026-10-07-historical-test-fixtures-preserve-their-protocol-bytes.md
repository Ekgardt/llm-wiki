# Historical test fixtures preserve their protocol bytes

Checked 2026-10-07. Actual Windows CI on Python 3.11, 3.13 and 3.14 exposed two fixture errors. A valid compile receipt was discarded alongside the invalid receipt, and the retained historical v3 BagIt fixture failed validation. Both fixture writers used platform text output, converting their recorded LF bytes to CRLF. The discard control failed before its intended evidence-scope parser; the bag failed its exact tag guard. These are fixture causes, not permission to loosen either production guard.

The fixtures now write the same UTF-8 bytes on every platform. Existing assertions and production readers are unchanged. Two new regression cases reproduce Windows text translation through real file output on any host: the original discard test must preserve its valid receipt, and every historical archive file must equal its original UTF-8 bytes. Both cases failed before correction. The related archive, receipt and compile-hardening tests passed on actual Python 3.10: 87 passed, no skips. Native Windows rerun remains required. Modified functions and all new test functions passed actual Python 3.10 AST/Lizard (maximum CCN2), and Ruff.

Alternatives considered: normalizing reader inputs would change historical protocol authority; changing expected results would conceal the false discard; relaxing the tag or evidence checks would weaken guards. Exact fixture restoration is the narrower correction. No product format, location, setting, dependency, limit or permission contract changes.

Primary sources checked on the date above: [Python text newline semantics](https://docs.python.org/3.10/library/functions.html#open), [Microsoft CRT text translation](https://learn.microsoft.com/en-us/cpp/c-runtime-library/file-translation-constants?view=msvc-170), and [RFC 8493 BagIt](https://www.rfc-editor.org/rfc/rfc8493). The bag specification does not justify changing the project's stricter captured historical bytes. Fresh native navigation at 0c46ad41 was supplemented with exact source and actual CI failures because graph coverage is partial.
