# Validated citation overlap is required compile context

Research and qualification date: 2026-10-07. This internal candidate builds on the separately frozen critic correction. It changes no persisted schema, source identity, runtime path, environment contract, provider selection, or receipt authority.

The compiler previously treated an existing page citing the selected physical source as optional word-ranked context. A real project-scoped accepted decision could therefore disappear while a draft generalized the same source into a global pattern. The isolated original regression reproduces the missing full decision. The critic correction separately preserves selected existing context and compact semantic claims; neither correction treats identical evidence as identical meaning.

The candidate resolves canonical references against the captured immutable original bytes through the existing EvidenceResolver. It retains every matching full note whose validated physical span overlaps a selected complete source unit. Historical part-version references require exact part bytes and a unique current physical origin before local offsets are projected. Repeated identical historical parts are unresolved; explicit original absolute spans retain their ordinary block and span checks. Native units still require complete companions and the existing current head, part, frame, and source proof. No successful filesystem, alias, DLP, or publication verdict is cached.

Required pages are selected before optional ranking. The existing input target grows only to the measured minimum needed for the complete source and all required pages, using the same sole qualified Codex model's advertised planning window. Unknown or insufficient capacity refuses the unit rather than dropping required context. This is an estimate of local serialized input, not proof of model wire capacity. It does not fill the larger window with optional material or change the grouping target. A transient, nonserialized required-path tuple prevents refresh from silently losing a previously qualified association. Refresh revalidates sources, pages, targets, model, budget, and manifests; publication retains normal CAS checks.

## Research and alternatives

[W3C PROV-DM](https://www.w3.org/TR/prov-dm/) distinguishes specific entities and their derivation. Exact source versions support association, not semantic equivalence. [Lost in the Middle, TACL 2024](https://aclanthology.org/2024.tacl-1.9/) provides primary experimental evidence that more context alone does not ensure useful evidence use; it is not a current Luna benchmark. [OWASP LLM01](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) supports treating source text and model output as untrusted and preserving downstream validation. These three independent primary sources were checked for this design on the date above.

A lexical threshold or fixed top-N can drop the exact accepted decision and introduces an unsupported limit. A whole-window optional fill previously increased context substantially without useful-cycle proof. Hash-based semantic deduplication would incorrectly remove distinct claims sharing evidence. A queue-wide resolver verdict cache would blur fresh authority checks. The chosen association is deterministic and snapshot-owned, retains complete bytes, and does not replace semantic review.

## Qualification and remaining limits

The original omission regression failed; the candidate retains the full page. Additional controls cover historical part offsets, repeated physical origins, wrong paths and digests, stale sources, insufficient or unknown model capacity, missing native companions, frame tampering, invalid DLP policy, refresh loss, current target CAS drift, and distinct same-evidence claims. Existing tests remain byte unchanged. Precise run counts, source hashes, measured test weights, and reports are recorded in the private frozen manifest.

An early orchestration error executed ten isolated cases after a failed complexity check. That passing run is explicitly not qualification. The failure and run logs are retained; subsequent qualification uses separate successful analyzer and Ruff steps before test execution. Earlier new-fixture failures concerning a valid alternate span, a nonoverlapping native preamble, and a CAS error message were retained and corrected without weakening existing assertions.

A metadata-only check of the real counterexample validates the existing decision's historical part reference against the captured current source and exact physical span. It proves association, not model quality, useful publication, or whole-cycle performance. The candidate does not cover all project instructions or semantically relevant pages lacking overlapping citations. Historical slices no longer represented by a uniquely proved current part remain unresolved. Existing output reservation and safety margin still lack a complete measured capacity basis; requested output tokens remain a planning reservation rather than an enforced CLI output limit. Larger source grouping, fallback replanning, all pending source work, and a useful paired model cycle remain open. This change does not close audit point 7.
