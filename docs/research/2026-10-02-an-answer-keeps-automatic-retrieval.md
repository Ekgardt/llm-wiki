# An answer keeps automatic retrieval

2026-10-02. The correction is installed under the existing maintenance fence, with preserved preimages and verified afterimages. Full answer-cycle qualification remains open.

The genuine grounded-answer trial missed registered source pages despite ordinary semantic recall finding them. The answer path turned query analysis into an explicit retrieval profile even when the caller supplied none. BASE then requested lexical search only; GRAPH requested lexical and graph only. This bypassed the existing automatic semantic planner, which adds dense search for a semantic query while preserving graph signals. Two corrected regression cases failed; three explicit-profile cases passed. The first test harness incorrectly named the planner and failed before this genuine comparison; that failure remains recorded.

The correction keeps the context compiler's selected profile but forwards None to retrieval when the caller supplied no profile. The existing planner chooses the actual signals for both initial retrieval and gap searches. An explicit caller profile retains its declared signals and normalization. No profile registry, graph, model, translated query, path, environment contract, tool, schema or numerical budget is changed.

Primary sources checked on 2026-10-02:

- [MCP tools specification, 2025-11-25](https://modelcontextprotocol.io/specification/2025-11-25/server/tools): declared caller arguments and their schemas are the interface; a caller's absent optional argument is not an explicit override.
- [Microsoft Azure hybrid-search overview](https://learn.microsoft.com/en-us/azure/search/hybrid-search-overview), updated 2026-08-31: lexical precision and vector similarity provide distinct signals; combining them is not equivalent to lexical search alone.
- [Sentence Transformers multilingual-model documentation](https://www.sbert.net/examples/sentence_transformer/training/multilingual/README.html): aligned multilingual embeddings can relate text across languages; this is not proof that a particular retrieval or answer is correct. The installed encoder remains pinned multilingual-e5-small, not a model replaced by this change.

Alternatives: enlarging the lexical result pool does not restore a missing semantic signal; adding Russian query keywords preserves language-dependent routing; changing the model or translating every request adds another intervention without repairing the caller/planner mismatch; forcing HYBRID discards explicitly selected profiles and graph behavior. Preserving the existing automatic planner and genuine caller overrides fixes the boundary directly. Dense search costs extra time and may be unavailable; existing deadline admission, optional-stage degradation and actual trace reporting remain.

Actual read-only paired retrieval used three fixed registered questions, existing generation and pinned models. Models were warmed by actual encoding and reranking; two generic admission calls and background joins were separately recorded. An initial import failure occurred before live work. A second harness failed after setup by treating public dictionary rows as dataclass objects; those logs and setup costs remain. The completed corrected comparison made no generative calls: the automatic path found the previously missing update decision at rank 2 and citation decision at rank 1, whereas the old explicit BASE/GRAPH paths found neither in five returned rows. The symlink case remained missing in both arms. Automatic retrieval took 10.605, 18.527 and 11.007 seconds versus 4.633, 12.595 and 7.777 seconds. These are retrieval measurements under the existing 120-second grounded budget, not full answer quality, native hook performance or a guarantee under the shorter ordinary-recall budget.

Verification: all five routing cases pass; related and mandatory checks passed 176 cases with three warnings in 73.13 seconds. Actual Lizard covers all six changed/new functions including the nested backend, maximum CCN 5. Source/path/deadline/provenance checks and the earlier insufficient ten-case answer results are preserved. Full answer-cycle qualification is still required before closing the audit.
