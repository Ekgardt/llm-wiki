## 3. Почему нельзя просто сравнить с опубликованными числами

Публикуемые системы на LongMemEval показывают 0,878–0,944. Прямое сравнение с
нашими 0,575 будет ложью по трём причинам:

- **Они отвечают на всё.** Их метрика — доля верных среди ответов, наша — доля
  верных среди вопросов. Мы намеренно молчим, когда доказательств нет.
- **Мы отвечаем только процитированным.** Каждое утверждение обязано опираться
  на проверяемый фрагмент, иначе оно не публикуется. Это снижает цифру и
  повышает то, чему можно верить.
- **Стенд считает молчание ошибкой.** В бэклоге стоит задача мерить на стендах,
  которые оценивают отказ отдельно (LIT-RAGBench, RefusalBench) — до этого
  сравнение остаётся односторонним.

Наша сопоставимая цифра — правильность среди отвеченного: на последнем прогоне
n=200 это 115 верных из 147 отвеченных, то есть **0,78**.

## Что из этого следует

По навигации мы лучше по качеству и втрое дороже — работать надо над отдачей с
токена, и самый крупный оставшийся кусок это сводка архитектуры.

По памяти сравнение с публикациями невозможно без стенда, который оценивает
отказ; своя динамика — с 0,21 до примерно 0,58 — есть, но требует трёх прогонов,
чтобы называться результатом.
